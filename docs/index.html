Elga Ace Bluetooth proxy

A standard ESPHome Bluetooth proxy that can also pair with a Remeha Elga Ace gateway. You only need to do this once per ESP32.

  1. Connect an ESP32 with a USB cable and use Chrome or Edge on a computer.
  2. Click Connect, pick the serial port, install, then enter your Wi-Fi details.
  3. Home Assistant discovers the proxy: add it under Settings → Devices & services.
  4. Add the Elga Ace integration and type the appliance PIN. That's it.
